# 1. PairFlow 第一版设计

## 1.1. 目标与批准范围

用户已批准：Lightroom Classic 插件，默认处理当前选中的 JPEG，在同一文件夹内匹配 RAW/DNG，预览后同步星级、颜色标签和选取/拒绝状态。Windows 和 macOS 共用 Lua 源码；不修改 Develop 参数。

## 1.2. 操作流程

1. 将 RAW 和 JPEG 分别导入目录，过滤 JPEG 并选片。
2. 选中待同步 JPEG，执行图库的附加模块菜单。
3. 选择同步字段，默认启用仅预览。
4. 预览匹配数量、未匹配和歧义清单。
5. 关闭仅预览后重新执行，确认后写入 RAW 的目录元数据。

## 1.3. 配对规则

- 只接受选中的 JPEG 原片，跳过虚拟副本及其他文件类型；未选择照片时不回退到整个胶片栏。
- 候选仅来自 JPEG 所在目录的同一文件夹，不包含子文件夹。
- 去掉最后一个扩展名后比较文件名，忽略英文字母大小写；RAW 和 DNG 都可作为目标。
- 单一候选直接配对；多个候选仅在拍摄时间存在且精确匹配能得到唯一目标时配对。
- 重复 JPEG 来源、多目标歧义、缺少目标以及目录读取错误都列入报告，不猜测。
- 虚拟副本不作为目标。

## 1.4. 写入边界

- 只复制用户勾选的 rating、label、pickStatus；颜色标签复制原始标签文字，兼容自定义颜色标签集并保留白色标签文本。
- JPEG 的零星级、无颜色和未选取状态也会覆盖对应 RAW；确认界面明示这一点。
- 执行前保留目标字段旧值，字段写入失败时尝试恢复当前照片的旧值，记录恢复失败。
- 每次在 Lightroom 写入上下文中处理一对照片，支持取消；取消保留已完成照片，并完整报告。
- 不保存 XMP、不复制文件、不调用外部程序、不删除照片、不修改修改照片参数。

## 1.5. 代码结构

- `PairFlow.lrplugin/Info.lua`：SDK 元数据与菜单入口。
- `PairFlow.lrplugin/Pairing.lua`：不依赖 SDK 的匹配逻辑。
- `PairFlow.lrplugin/CatalogAdapter.lua`：选择读取、文件夹候选、元数据写入。
- `PairFlow.lrplugin/Report.lua`：摘要与可复制的明细。
- `PairFlow.lrplugin/Sync.lua`：异步任务、选项、确认、进度与结果。
- `README.md`：安装、工作流、配对规则、验证限制。

## 1.6. 验证

按用户要求不新增单元测试。执行 Lua 5.1 语法检查、临时模拟目录验证（不进入项目测试套件）以及 `git diff --check`。实际插件加载、颜色标签和 Pick 状态效果需在 Lightroom Classic 实机中验证；不会把静态或模拟检查当作实机结果。
