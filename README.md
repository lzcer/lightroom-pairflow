# 1. 简介

**Lightroom PairFlow** 是一个 Lightroom Classic 插件，用来同步同一张照片的 JPEG 和 RAW 选片标记。

拍摄 RAW+JPEG 后，可以先看相机直出的 JPEG 挑选照片、打星或添加颜色标签，再把这些标记同步到对应的 RAW。之后在 Lightroom 中按标记筛选 RAW 调色，就不用逐张寻找对应文件了。也支持将 RAW 上的标记同步回 JPEG。

插件适用于 Windows 和 macOS 上的 **Lightroom Classic**，不适用于 Lightroom 云端版。

# 2. 功能介绍

**同步字段**

支持同步星级、颜色标签、选取/拒绝状态。三个字段可以分别勾选，插件会记住字段选择；颜色标签支持自定义标签文本。

**同步模式**

| 模式 | 处理方式 |
| --- | --- |
| 自动（默认） | 选中的 JPEG 同步到对应 RAW/DNG，选中的 RAW/DNG 同步到对应 JPEG，支持混合选择 |
| JPEG → RAW | 只将选中的 JPEG 标记同步到对应 RAW/DNG |
| RAW → JPEG | 只将选中的 RAW/DNG 标记同步到对应 JPEG |

例如，自动模式下选中 10 张 JPEG 和另外 5 张照片的 RAW，会分别完成 10 组 JPEG → RAW 和 5 组 RAW → JPEG 同步。另一种格式的照片无需同时选中，也无需显示在当前过滤结果中。

**同时选中一对照片时**

自动模式会将同一组 JPEG 和 RAW 合并处理一次：

- 仅一边有星级：勾选同步星级时，将已有星级复制到另一边。
- 两边都有星级：视为冲突，跳过整组并报告双方星级。即使星级相同，或未勾选同步星级，也会执行此保护规则。
- 两边都没有星级：保持零星级。
- 勾选的颜色标签或选取/拒绝状态不同：只跳过冲突字段，其他非冲突字段仍可同步。空值与非空值不同也视为冲突。

固定方向模式，以及自动模式只选中一边时，来源的零星级、空颜色标签、未选取状态也会覆盖目标对应值。

**配对与预览**

照片必须位于同一个文件夹，基础文件名相同，且两种格式都已导入 Lightroom。例如 `DSC_0123.JPG` 对应 `DSC_0123.NEF`，文件名比较忽略英文字母大小写。多个同名候选会尝试按拍摄时间确定唯一目标；找不到目标或无法唯一配对时会跳过并报告。虚拟副本不参与同步。

每次打开默认使用自动模式，**仅预览默认不勾选**。勾选后只显示配对、计划变更和冲突，不写入标记。预览报告点击“完成”或“取消”都会返回设置窗口，并保留选项，可以直接接着正式执行。

插件只修改 Lightroom 目录中的标记，不修改调色参数，不主动保存 XMP，不复制、移动或删除照片。执行中取消会保留已完成的同步；报告会列出失败和未执行项，内容可以全选复制。如果 Lightroom 开启了自动写入 XMP，Lightroom 自身仍可能将标记写入文件或附属文件。

# 3. 安装及使用

**安装插件**

1. 下载项目文件；如果下载的是 ZIP，先解压，保留完整的 `PairFlow.lrplugin` 文件夹。
2. 打开 Lightroom Classic 的 **文件 → 增效工具管理器 / 附加模块管理器**（File → Plug-in Manager）。
3. 点击 **添加**，选择 `PairFlow.lrplugin` 文件夹。
4. 在 **图库 → 增效工具额外信息 / 附加模块选项**（Library → Plug-in Extras）中，选择 **PairFlow：同步 RAW/JPEG 选片标记...**。

更新插件文件后，在附加模块管理器中重新载入插件。

**准备照片**

1. 将 RAW 和 JPEG 放在同一个文件夹，保留相同的基础文件名。
2. 在 Lightroom Classic 首选项中勾选 **将 RAW 文件旁的 JPEG 文件视为单独的照片**（Treat JPEG files next to raw files as separate photos）。
3. 将 RAW 和 JPEG 都导入 Lightroom 目录。已经导入 RAW 的文件夹，可以通过“同步文件夹”补充 JPEG。

**看 JPEG 选片，再同步到 RAW**

1. 在图库过滤器中只显示 JPEG，挑选照片并设置星级、颜色标签或选取状态。例如用绿色表示直接使用 JPEG，红色表示需要调整 RAW。
2. 选中需要同步的 JPEG，打开 PairFlow。无需取消 JPEG 过滤，也无需选中 RAW。
3. 保持自动模式，勾选需要同步的字段。
4. 如需先核对，勾选“仅预览”并点击“继续”。检查报告后，点击“完成”或“取消”返回设置，再取消勾选“仅预览”。
5. 点击“继续”，在确认窗口中点击“同步”，完成后查看执行报告。
6. 按 RAW/DNG、星级和颜色标签筛选需要调色的照片。直出照片使用原 JPEG；需要调色的照片编辑 RAW 后导出 JPEG。

反向同步时，选中 RAW 并使用自动模式或 RAW → JPEG 模式即可。插件只处理打开时选中的原片；未选中照片时直接退出。首次使用建议先选少量照片核对预览和实际结果。
