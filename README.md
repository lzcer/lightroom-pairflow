# 1. Lightroom PairFlow

Lightroom Classic 的 RAW+JPEG 选片辅助插件：看相机 JPEG 选片，将星级、颜色标签和选取/拒绝状态同步到对应 RAW/DNG，随后只处理需要调色的 RAW。

## 1.1. 安装

1. 保留完整的 `PairFlow.lrplugin` 文件夹。
2. 在 Lightroom Classic 中打开 **文件 → 增效工具管理器 / 附加模块管理器**（File → Plug-in Manager）。
3. 点击 **添加**，选择 `PairFlow.lrplugin` 文件夹。
4. 回到图库，打开 **图库 → 增效工具额外信息 / 附加模块选项**（Library → Plug-in Extras），选择 **PairFlow：同步 JPEG 到 RAW...**。


更新源码后，在附加模块管理器中重新载入插件。插件使用 `com.lzcer.lightroom.pairflow` 作为固定标识，保存的字段选择沿用该标识。

## 1.2. 推荐工作流

1. 将相机 RAW 和 JPEG 复制到同一文件夹，保留相同基础文件名。
2. 在 Classic 首选项中勾选 **将 RAW 文件旁的 JPEG 文件视为单独的照片**（Treat JPEG files next to raw files as separate photos）。
3. 将两种文件分别导入 Lightroom 目录。已经导入过的目录，可同步文件夹以补充 JPEG，避免重复导入原有 RAW。
4. 在图库元数据过滤器中仅显示 JPEG，选片并打星。可用绿色表示直接使用 JPEG、红色表示需要调整 RAW。
5. 选中要同步的 JPEG，运行 PairFlow。无需取消 JPEG 过滤，也无需选中 RAW。
6. 保持默认 **仅预览**，检查报告中每一组 JPEG → RAW 配对。
7. 再次执行插件，取消 **仅预览**，选择需要同步的字段，确认后执行。
8. 用“RAW/DNG + 星级 + 红色标签”过滤待调色照片。直出照片复制原 JPEG；调色照片编辑 RAW 后导出 JPEG。

未选中任何照片时插件直接退出，不会处理整个胶片栏。选中项里的 RAW、其他文件类型和 JPEG 虚拟副本都会被忽略。

## 1.3. 配对规则

| 情况 | 处理方式 |
| --- | --- |
| `DSC_0123.JPG` 和同目录 `DSC_0123.NEF` | 配对 |
| 文件名英文字母大小写不同 | 忽略大小写比较 |
| RAW 未导入 Lightroom | 跳过并报告；不会自动导入 |
| 只有其他文件夹或子文件夹中有同名 RAW | 跳过 |
| 多个同名 RAW/DNG，其中一个拍摄时间精确对应 | 选取该唯一候选 |
| 多个候选没有拍摄时间，或时间匹配仍不唯一 | 跳过，不猜测 |
| 同一文件夹选中多个同名 JPEG 来源（如 `.jpg` 和 `.jpeg`） | 全部跳过，避免覆盖冲突 |
| RAW/DNG 虚拟副本 | 排除候选 |

拍摄时间使用 SDK 的 `dateTimeOriginal` 数值精确比较，不使用时间容差；单一同名候选不要求时间一致。候选来自当前 Lightroom 目录的文件夹记录，离线照片也能同步目录中的标记。

## 1.4. 写入行为

- 三个字段可独立勾选，默认为全部勾选；字段选择会保存。
- **仅预览每次默认开启**，不会沿用上次的正式执行状态。
- JPEG 的零星级、空颜色标签、未选取状态也会覆盖 RAW 对应值。
- 颜色标签复制实际标签文本，因此自定义标签集和白色标签文本可以保留。
- 已经一致的目标不重复写入，报告显示“已一致”。
- 每对照片单独处理；某对失败不阻止后续配对。字段写入失败时尝试恢复该照片的旧值，恢复失败会在报告中明确标记。
- 取消保留已完成的配对，并将剩余配对列为“未执行”。
- 不修改 Develop 参数，不保存 XMP，不复制、移动或删除照片。
- 如果目录开启了 Lightroom 的“自动将更改写入 XMP”，Lightroom 自身可能把目录变更写入文件或附属文件；插件不更改这项设置。

## 1.5. 报告

报告包含选中 JPEG 原片数、唯一配对数、跳过数、忽略数，以及每组来源和目标路径。执行后另列更新、已一致、失败和未执行数量。文本框支持全选并复制，关闭后不自动保存到磁盘。

## 1.6. 验证与限制

开发验证区分 Lua 5.1 语法检查、模拟 SDK 检查和 Lightroom 实机检查。语法或模拟执行成功不代表已在 Lightroom Classic 中加载并实际同步成功。

首次使用可先在少量 RAW+JPEG 样片或测试目录中验证：

1. 给 JPEG 设置星级、颜色和 Pick/Reject，先运行仅预览并核对配对。
2. 正式运行后确认 RAW 三个状态相同，且 Develop 参数没有变化。
3. 清空 JPEG 标记后再次运行，确认 RAW 状态也清空。
4. 只勾选星级，确认其他两个字段不受影响。
5. 加入缺少 RAW 的 JPEG，以及有多个同名 RAW/DNG 的 JPEG，确认跳过和时间消歧符合规则。

当前版本只同步当前选中 JPEG，不创建待调色集合，不做自动选片，不调整 RAW 预览色彩。
